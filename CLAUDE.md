# Trella Project AI Rules

This project follows a strict set of architectural and coding rules organized in the `.ai/` directory.

**Before starting any task, you MUST read and follow the guidelines in these files:**

- **Architecture Rules:** `.ai/ARCHITECTURE.md`
- **Coding & UI Rules:** `.ai/CODING_RULES.md`
- **Open Source Policy:** `.ai/OPEN_SOURCE_POLICY.md`
- **AI Integration Rules:** `.ai/AI_INTEGRATION_RULES.md`
- **Module Structure:** `.ai/MODULE_TEMPLATE.md`

## Prompts
If you are asked to research, implement, or review, refer to the prompt templates in `.ai/PROMPTS/`:
- `.ai/PROMPTS/research.md`
- `.ai/PROMPTS/implement.md`
- `.ai/PROMPTS/review.md`

**Core Principle:** *Never reinvent the wheel. Always extend, never rewrite. Follow the Repository -> Service -> Router architecture.*
